# 🚀 Quick Start Guide

## Быстрый запуск за 3 шага

### 1. Установка зависимостей

```bash
# Убедитесь что FFmpeg установлен
ffmpeg -version

# Запустите скрипт установки
chmod +x setup.sh
./setup.sh
```

### 2. Запуск приложения

```bash
# Активируйте виртуальное окружение
source venv/bin/activate

# Запустите сервер
python run.py
```

### 3. Откройте веб-интерфейс

Откройте в браузере: **http://localhost:8000/static/index.html**

---

## 🐳 Запуск с Docker

```bash
# Сборка и запуск
docker-compose up -d

# Просмотр логов
docker-compose logs -f

# Остановка
docker-compose down
```

## 📝 Быстрый пример

### Сравнить два голоса:

1. Откройте вкладку "Compare Speakers"
2. Вставьте URL видео первого спикера
3. Вставьте URL видео второго спикера
4. Нажмите "Compare Speakers"
5. Дождитесь результата

### Пример результата:

- **Similarity Score**: 87.5% - Высокая вероятность что это один человек
- **Confidence**: 92.3% - Высокая уверенность в результате
- **Quality**: Excellent - Отличное качество аудио
